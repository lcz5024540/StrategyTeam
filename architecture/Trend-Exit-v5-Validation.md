# 趋势退出 v5 实验与验收合同

本文件定义未来实现的验证方式，**没有 v5 回测结果，也不声称 v5 比 v4 更赚钱**。目标是判断减少过早退出之后，净收益、尾部风险与资金效率是否共同可接受。

前置：[技术设计](CoinStrategy-Trend-Exit-Design-v5.md)、[事故证据](../docs/architecture-refactor/evidence/HTX_TREND_SHORT_HOLDING_20261009.md)。发布顺序见 [图11-4](../docs/design-docs/diagrams/trend-exit-v5-rollout.drawio)，决策断言见 [图11-2](../docs/design-docs/diagrams/trend-exit-v5-decision.drawio)。

## 2. 分层证据

| 层 | 输入 | 能得出的结论 | 不允许的结论 |
|---|---|---|---|
| L0 规则单元 | 人工构造且完整的确定性输入 | 决策合同符合预期 | 盈利能力 |
| L1 事故重放 | 真实旧版输入、订单、费用、决策序列 | 重现旧行为，定位新旧分歧 | 仅靠旧退出前轨迹推断新退出净收益 |
| L2 固定入场对照 | 同一实际入场、完整后续行情与费用/执行模型 | 隔离退出规则的影响 | 等同于新的完整策略权益 |
| L3 全组合重放 | 全候选、gate、资金、并发占用、再入场、执行证据 | 策略级权益、风险与交易次数 | 用互相重叠的“独立单笔收益之和”当组合收益 |
| L4 OBSERVE/PAPER | 同源线上输入、隔离状态与明确成交模拟 | 稳定性、数据时效和执行模拟质量 | 实际成交保证 |
| L5 小仓 | 批准范围内实际订单和fills | 实盘执行成本及风险 | 自动推广所有币种/模型/账户 |

缺完整反事实订单簿时，允许报告明示假设的 OHLC 敏感性模拟，但与 L2/L3 的执行级证据分开，不能作为直接实盘晋级依据。若原始同源回放合同要求完整证据，则输出 `INSUFFICIENT_EVIDENCE`。

## 3. 数据冻结与防泄漏

每个实验 manifest 必含：数据起止UTC、universe、模型版本、源码commit、policy_hash、费率来源、订单簿来源、资金费来源、样本切分、排除理由、随机种子（仅统计抽样）、实验预算和结果路径。

先冻结 manifest，再计算结果。已查看的 LTC309/DOGE307/BTC303 等是调试集，不能混入最终样本外成绩证明。所有分组共享数据与成本合同；改变退出时必须获取旧退出之后的行情和资金费，不能复制旧平仓成交价当新策略成交价。

按时间顺序训练/验证/最终留出，研究起点比例50%/25%/25%；切分边界按最大允许持仓期限 purge/embargo，跨边界持仓不泄漏未来结果。比例本身不构成充分性，最终报告必须展示实际样本量和市场状态覆盖。

不得先查看测试结果，再换阈值并继续称同一测试集为独立。失败后重新设计需新版本与新的未来留出数据。

## 4. 预注册实验组

| 实验 | 变化 | 目的 |
|---|---|---|
| E0 | 当时实际v4，按部署日期区分binary/policy | 真实基线，不把10-07与10-08分支差异抹平 |
| E1 | 仅替换持仓模型评估，取消FLAT独立失效 | 验证入场/持仓口径差异影响 |
| E2 | E1 + post-entry closed-bar成熟与确认 | 验证实时提前分支影响及确认代价 |
| E3 | E2 + 显著盈利/波动/成本激活与软线 | 验证保护门槛，分析回吐尾部 |
| E4 | E3 + 一次结构减仓 | 验证部分动作是否改善而非增加费用 |
| E5 | 完整v5 + 再入场/资金占用 | 验证真实组合结果与结构循环 |
| E6 | 可选灾难跟踪硬边界 | 独立实验，不默认混入E5改善结论 |

先测试 R0 合同，再做小规模候选敏感性分析。只在验证集选择有限方案，搜索预算上限研究初值24个配置；最终测试只评价冻结的单个候选。不能一轮同时改入场、杠杆、费用和退出再将改善归因于退出。

## 6. 指标与统计口径

| 指标 | 定义 | 解释边界 |
|---|---|---|
| 净收益 | 实际/模拟毛收益-全部手续费-未含价格冲击+净资金费 | 报告币种、时间、版本与价格模型 |
| PF | 正净收益总和 / 负净收益绝对值总和 | 分母0标NA，不报无穷大提升 |
| 胜率/期望 | 同口径已结束episode | 部分减仓不当作多个独立盈利样本 |
| 最大回撤 | 含未实现损益的组合权益峰谷 | 不用只有已平仓的曲线掩盖浮亏 |
| 尾部损失 | 单笔损失分位/CVaR与硬止损执行偏差 | 研究统计量，不是损失上界保证 |
| 手续费负担 | 总费用/正毛利润总和，及总费用/成交名义 | 正毛利润分母为0时NA，并保留费用绝对值 |
| 持仓时长 | 交易所首笔entry fill至最后exit fill | 无交易所时刻则明确为系统确认代理指标 |
| 软退出不足一bar比例 | 非硬风险退出中不足一个完整bar的比例 | v5严格合同应为0，不含真实硬止损 |
| 再入场次数 | 按结构lineage、账户、币种方向计数 | 不能靠新run_id低估 |
| 资金效率 | 扣费净收益 / 占用保证金时间积分 | 同杠杆预算下比较 |
| MFE捕获率 | 实际净收益 / 可观测正MFE | MFE≤0则NA；成交模型限制必须披露 |

使用按时间块聚类的配对bootstrap报告v5-v4净收益差异区间，避免把同时相关币种视为独立样本；区间方法、块长在验证集前冻结。净收益、回撤和样本数量同时报告，不仅报告最好看的PF。

## 7. 晋级门槛

以下为提议验收门槛，非已达成绩；改变门槛必须在新实验运行之前改 manifest，并解释原因。

| 门 | 通过条件 | 失败处理 |
|---|---|---|
| G0 证据 | 实际纳入交易的执行数据完整；镜像/未知样本单列，不静默丢弃 | 数据补齐或仅L1，不报执行级经济结果 |
| G1 合同 | T-01..T-36通过；双语言golden全字段通过 | 修实现，不以收益好掩盖安全失败 |
| G2 样本 | 最终留出≥100已结束episode；拟上线的每个模型/方向至少30；覆盖趋势与震荡 | 样本不足，延长观测；不降低阈值凑数 |
| G3 经济 | 基准及保守成本下整体净收益>0、PF>1；相对同口径v4净收益差异的95%区间下界>0 | 不晋级；减少费用但净收益差不能通过 |
| G4 风险 | 组合最大回撤和尾部损失不劣于基线，且低于预注册绝对风险预算 | 重做设计/范围；不能临时扩大预算 |
| G5 稳定性 | 同一冻结版本至少14天OBSERVE/PAPER并覆盖预定样本；执行安全失败0 | 日数满但样本不足仍不通过 |
| G6 实盘 | 用户批准账户/模型/金额；原生保护及回滚演练完成 | 保持观察，不自动切换 |

G2是最低证据门，不保证统计功效；报告应给置信区间与未覆盖区域。各模型/方向可分别不通过，不用整体收益掩盖某类持续亏损。

基准成本用真实账户费率、方向盘口与实际资金费；保守成本采用独立时期的滑点上尾和压力延迟，参数在运行前冻结。零成本结果只能帮助归因，不用于批准实盘。

绝对风险预算（账户最大可承受损失、单日损失、总敞口、回撤）需策略负责人在M7/M10前填写；未填写属于失败关闭，不在本文猜测用户资金容忍度。

## 8. 事故预期与反例

- LTC309/DOGE307：0个完整post-entry bars不应触发软FULL_CLOSE；这只证明消除已识别的提前路径，不保证后续收益为正。
- BTC303/LTC299：微小历史净MFE不自动转换为成本线；仍需合格bar推进和v5双门槛。
- ZEC297：硬初始风险触发不能被等待确认推迟；此案例是防止修复过度的反例。
- ETH305：已持有较久也可能合理退出；不能为了提高中位持仓时间而阻止全部退出。
- 镜像38 ACCEPTED：先收敛真实成交，不能将此批数据当38笔当前未平仓或38笔零收益交易。

## 9. 最终报告要求

报告固定包含：实验manifest、数据完整性、逐组变更、留出与排除样本、成本假设、净收益与回撤、置信区间、失败案例、成交误差、模型/方向分组、是否满足G0..G6、明确下一步。结果为否时也完整入仓。

需同时给出固定入场对照和全组合路径；后者必须重算延长持仓后的资金占用、其他候选被阻挡、再入场及镜像差异。不允许把L2的“每笔都更好”直接替代L3权益。

本次设计自检只验证文档/链接/图示及事实一致性。未执行应用测试、生产SQL、部署或实盘参数变更。
