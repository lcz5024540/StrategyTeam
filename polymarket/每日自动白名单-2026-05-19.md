# 每日自动白名单 Job 已落地

## 你要的功能

> "每天抓取一次一周的最高 PNL 地址，胜率 top10 且一周订单超过 30 笔，pnl 高的地址默认加白。"

## 落地物

### 1. 新增配置类 `AutoAllowlistConfig`

`coin-strategy-common/.../config/SmartWalletProperties.java` 末尾新增内部静态类:

| 字段 | 默认值 | 含义 |
|------|--------|------|
| `enabled` | `false` | 总开关 (yml 显式打开) |
| `cron` | `0 0 6 * * *` | 每天 06:00 (Asia/Shanghai) |
| `zone` | `Asia/Shanghai` | |
| `topN` | `10` | 取前 10 |
| `minLifetimeTrades` | `30` | 历史 total_trades >= 30 (排单笔暴富) |
| `minRecent7dTrades` | `1` | 7d 内至少 1 笔 |
| `activeWithinDays` | `7` | lastTradeAt 在 7 天内 |
| `minPnlUsdc` | `$10,000` | realized PnL 下限 |
| `minWinRate` | `0.55` | 胜率下限 |
| `maxDrawdown` | `0.30` | 最大回撤上限 |
| `stakeMultiplier` | `0.50` | 入库 stake 倍数 |
| `defaultMode` | `PAPER` | 默认 PAPER, 不动 LIVE 资金 |
| `expirationDays` | `30` | 30 天后过期 (cleanupExpired 自动清) |
| `overwriteExisting` | `false` | 已 ACTIVE 的不动 |

### 2. 新增 Job `WeeklyTopLeaderAutoAllowlistJob`

`coin-strategy-job/.../service/WeeklyTopLeaderAutoAllowlistJob.java`

核心逻辑:

1. `@Scheduled(cron=...)` 每天触发
2. `profileStoreService.listAll()` 拉全部 polymarket profile
3. 依次过滤: PnL → totalTrades → winRate → maxDrawdown → recent activity (recentTradeCount7d ≥ 1 **或** lastTradeAt 在 7 天内)
4. 按 winRate 降序 (相同则按 PnL 降序) 取 TOP N
5. 对每个候选 `manualAllowlistService.upsert(addr, request)` 入 manual_allowlist:
   - status=ACTIVE
   - mode=PAPER
   - stake_multiplier=0.50
   - expires_at = now + 30 天
   - reason 带原始 PnL/trades/winRate 便于日后回溯
   - created_by=`WeeklyTopLeaderAutoAllowlistJob`
6. 日志一行 summary: `scanned=X candidates=Y picked=Z inserted=A updated=B skipped=C failed=D | rejects: pnl=. trades=. winRate=. drawdown=. inactive=.`

防重: 单实例 `AtomicBoolean running`, 上一轮没跑完跳过这轮.

非破坏: `overwriteExisting=false` 时已 ACTIVE 的钱包不会被覆盖参数. 也不会主动 DISABLE 任何旧条目 (过期清理走 `cleanupExpired`).

       DATE(expires_at) AS expires, LEFT(reason, 80) AS reason, created_by

ORDER BY id DESC
LIMIT 20;

## 风险与回滚

| 风险 | 缓解 |
|------|------|
| 误加把人质量低 leader | PAPER 模式不动钱; 30 天自动过期; reason 字段留 PnL/winRate 痕迹 |
| 量太大撑爆 manual_allowlist | topN=10 限定每天最多 10 条; overwriteExisting=false 不重复 |
| 旧 allowlist 误删 | Job 永不 DISABLE/DELETE, 只 INSERT 或 UPDATE |
| jar 编译失败 | 旧 jar 已备份为 `app.jar.bak-<TS>`; `sudo cp` 回滚即可 |
| Cron 失控 | yml 改 `enabled: false` + 重启, 即停 |
