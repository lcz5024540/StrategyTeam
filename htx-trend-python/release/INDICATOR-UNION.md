# 五模式并集：待选择档位的 Python 候选

2026-11-04。五个模式已经接入现有 IOC 开仓与持仓管理；安装不启用交易，三档分别验证，启用时由用户选择。

| 模式 | 条件（多空对称） |
|---|---|
| M1 | 15m影线拒绝 + 1h CCI20同向 + 前20根1h通道中线同向 |
| M2 | 15m影线拒绝 + 前20根1h通道中线同向 |
| M3 | 15m影线拒绝 +（1h MACD柱或CCI20同向） |
| M4 | 可执行盘口穿越此前已知EMA9 + 15m CMF20同向 + 价差≤5bp |
| M5 | 15m影线拒绝 + 1h MACD柱同向 + 价差≤10bp |

影线条件：新闭合15m阳线、下影≥实体、bid>收盘为多头，阴线/上影/ask<收盘为对称空头。每次新闭合bar首次有效报价检查影线；EMA穿越用上一条有效报价及当时已知EMA。启动、重连、超过2秒缺口先建立基线，不补历史机会。指标使用SMA种子EMA、Wilder ATR14；MACD=EMA12−EMA26−DEA9，通道排除最新bar。信号冻结触发时指标，提交前复核当前盘口仍确认；窗口修订不重建同bar机会。

并集采用“任一模式命中”。同实例/合约/方向/15m bar只有一个机会身份，保存全部命中标签，不累计五份仓位。相反方向同次命中拒绝。已拒绝、零成交、部分成交或结果未知均不换身份追单。原保护退出重入检查仍执行。

| `HTX_UNION_EXIT` | 止损距离 | 止盈距离 |
|---|---:|---:|
| `ATR_1_1` | 1 ATR | 1 ATR |
| `ATR_2_1` | 2 ATR | 1 ATR |
| `ATR_2_2` | 2 ATR | 2 ATR |

距离以触发时可执行参考价计算并按真实tick取整，提交前冻结。IOC成交后不重新拉远止损；执行最差限价可能令实际风险收益比不同于上述距离。目标/止损按可执行盘口触及后全平，目标退出使用独立`INDICATOR_BRACKET_V1`，不套V4趋势保护。目标只是价格目标，扣费后仍可能亏损。没有新增净R阈值、300U本金或0.5%单笔风险筛选；实际发单仍使用环境原有资金、数量、深度、价差、追价、费用、资金费及总风险检查，并记录拒绝原因。

## 配置与验证步骤

1. 在隔离PAPER环境配置既有账户、合约池、资金与风险参数；添加 `HTX_RT_CANDIDATE=INDICATOR_UNION_V1`，以及上表明确选择的 `HTX_UNION_EXIT`。缺少档位直接拒绝启动，默认 `HTX_RT_ENTRY_ENABLED=false`。独立持久目录沿用现有配置。
2. 对三档分别运行：`python -m pytest -q htx-trend-python/tests/test_indicator_union.py`。测试用合成行情、实际worker/broker/账本/manager验证开平仓；不是盈利回测。
3. 如需离线包，分别用 `python htx-trend-python/release/package.py build --union-exit ATR_1_1 --out-root /absolute/path/paper-ATR_1_1`；另两档更换档位和输出根目录。LIVE代码包用`build-live --union-exit ATR_1_1`，也保持入口关闭。包哈希和配置指纹分别绑定档位；包名可能相同，必须分目录并按SHA识别。打包不创建试运行或部署授权。
4. 正式启用前逐档做完整实时PAPER验证，确认账户配置、tick精度、费用、持仓恢复、拒绝计数及收益/回撤；然后用户明确选择档位与启用环境。既有trial封印不自动适用该候选。本轮没有生产SQL、部署、订单或收益准入。

## 恢复与回滚

PAPER复用原账本与compact证据；LIVE复用`htx_trend_realtime_plan`及订单意图表，无新增业务迁移。首次使用仍需已有显式迁移，worker只验表。每笔仓保存模型、命中标签、触发bar、ATR、目标/止损、退出档位、实现封印和费用。源码封印含并集模块；只兼容已核验的00765365前版本向量，不接受任意旧哈希。

IOC使用明确限价，不转市价；部分成交只管理实际仓量，超时沿原client ID查询。目标与止损共用未决平仓管理，先撤未成交入场余量，未知平仓先对账，再按剩余数量reduce-only。紧急退出复用既有退出执行，可吃单。PAPER入场采用配置延迟后的有效L1盘口；平仓沿用现有可执行报价成交模拟，不保证全数量真实深度成交。

回滚先关闭新入口，保留本版本管理进程直到新模型仓全部结束；禁止直接切回不认识该模型的旧包。旧持仓按原模型/参数继续管理，不改4H入口。
