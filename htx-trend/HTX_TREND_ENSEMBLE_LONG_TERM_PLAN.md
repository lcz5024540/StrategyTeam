# HTX 多资产多周期趋势策略长期组合规划

## 结论

趋势策略长期不应是一条固定的海龟突破规则，而应是一套“多资产、多周期、多模型、统一风控”的趋势组合。当前已上线的 XAUT-USDT Donchian 突破策略只作为实盘链路验证版：它验证了 K 线信号、真实合约下单、订单账本、仓位账本、实盘开关和外部持仓保护。下一阶段要把它升级为组合策略引擎，让 BTC、ETH、XAUT 等标的都能在 15min、30min、1h、4h 上捕捉各自级别的趋势，同时由统一风险预算控制回撤。

长期目标不是“提高开单频率”本身，而是提高单位风险收益：能做小趋势，也能等待大趋势；能开更多高质量单，但横盘、手续费、资金费、滑点和相关性风险都必须先被扣掉。

## 核心原则

第一，入场模型可以多，风控只能统一。突破、回调、动量恢复、波动扩张都可以给出候选信号，但最终是否下单、下多少、是否已有相关风险敞口，必须由统一的 `RiskAllocator` 决定。

第二，多周期不是互相确认到没有交易，而是分工。15min / 30min 负责小趋势机会，1h 负责方向约束，4h 负责市场状态和风险偏置。BTC/ETH 可以更积极使用 15min/30min，XAUT 更偏 30min/1h，因为波动和手续费占比不同。

第三，策略组合要记录“为什么开仓”和“哪个模型贡献收益”。每一笔订单都需要记录触发模型、周期、分数、风险预算、止损来源、退出原因。否则后续无法判断到底是突破赚钱、回调赚钱，还是某个模型在消耗手续费。

第四，不急着上复杂模型。机器学习、盘口微结构、情绪因子可以进入研究池，但第一版组合应先用可解释的趋势模型。趋势系统先活下来，再谈增强。

## 标的池分层

| 层级 | 标的 | 角色 | 策略倾向 | 初始风险预算建议 |
|---|---|---|---|---|
| Tier 1 | BTC-USDT | 核心趋势锚 | 15min/30min/1h 都可交易，适合突破、回调、动量恢复 | 组合风险的 35% |
| Tier 1 | ETH-USDT | 高弹性趋势锚 | 比 BTC 更适合动量恢复和回调顺势，仓位略低于 BTC | 组合风险的 30% |
| Tier 2 | SOL-USDT、BNB-USDT 等 | 扩展高 beta | 只在流动性、点差、资金费达标时启用，先 shadow | 组合风险的 15% |
| Defensive | XAUT-USDT | 低波动/低相关补充 | 更适合 30min/1h 回调和波动扩张，突破只作强信号 | 组合风险的 10% |
| Research | 新币或低流动性标的 | 观察池 | 只记录信号，不实盘 | 组合风险的 0%-10% |

这里的百分比是“风险预算”，不是本金分配。比如 BTC 和 ETH 同时出现同方向信号时，不能简单相加满仓，因为它们高度相关；组合层要按相关性折减。

## 周期组合

| 周期 | 用途 | 适合模型 | 注意事项 |
|---|---|---|---|
| 15min | 小趋势、短线动量、快速回调恢复 | 动量恢复、EMA 回调、短 Donchian、SuperTrend | 交易成本敏感，必须严格点差/滑点过滤 |
| 30min | 主力小趋势周期 | EMA 回调、Keltner 扩张、Donchian 中短突破 | 适合 BTC/ETH/XAUT 的第一主战周期 |
| 1h | 趋势方向与中周期入场 | EMA 斜率、TSMOM、Donchian、ATR trailing | 可作为多数入场的方向过滤 |
| 4h | regime 判断和风险偏置 | EMA 斜率、收益率趋势、波动状态 | 不要求每笔都同向，但逆 4h 要降仓 |

长期组合不应要求所有周期完全同向，否则 15min/30min 小趋势会被过滤掉。更合理的是给每个周期权重：15min/30min 决定触发，1h 决定主方向，4h 决定仓位系数。

## 模型池

### 1. Breakout Sleeve：突破模型

用途是捕捉趋势启动和强趋势延续。当前 Donchian 版本属于这一类。

入场示例：

- 多头：收盘价突破 N 根 K 线高点，且 1h 方向不为空头。
- 空头：收盘价跌破 N 根 K 线低点，且 1h 方向不为多头。
- 过滤：ADX 达标、ATR 百分位达标、点差低于阈值。

适合：BTC/ETH 大波段、XAUT 强趋势阶段。

风险：假突破多，横盘阶段手续费消耗明显。

### 2. Pullback Sleeve：趋势回调模型

用途是在已有趋势中，不等新高/新低，利用回调后的恢复开仓。

入场示例：

- 多头趋势：价格回踩 EMA20/EMA50 区域，随后重新收回 EMA20，短周期动量转正。
- 空头趋势：价格反弹到 EMA20/EMA50 区域，随后重新跌回 EMA20 下方，短周期动量转负。
- 过滤：回调不能击穿趋势失效位，成交/波动不能过度萎缩。

适合：BTC/ETH 30min/1h，XAUT 30min/1h。

风险：趋势已结束时容易接飞刀，所以必须配“趋势失效止损”。

### 3. Momentum Recovery Sleeve：动量恢复模型

用途是捕捉短周期重新加速，尤其适合小趋势。

入场示例：

- 过去 M 根收益率转正/转负。
- MACD histogram 从收缩转扩张。
- 连续 K 线实体方向恢复，并突破短期均值。

适合：BTC/ETH 15min/30min。

风险：短周期噪音高，必须要求预期空间大于手续费和滑点的多倍。

### 4. Volatility Expansion Sleeve：波动扩张模型

用途是在低波动压缩后捕捉趋势启动。

入场示例：

- Bollinger Band Width 或 Keltner Channel 宽度从低分位扩张。
- 收盘价突破通道，同时 ATR percentile 上升。
- 方向由 30min/1h EMA 确认。

适合：BTC/ETH 的盘整后启动，XAUT 的低波动后扩张。

风险：只扩波动不代表有方向，需要方向分配合。

### 5. SuperTrend / ATR Band Sleeve：趋势线模型

用途是用 ATR 自适应趋势线做方向和退出参考。

入场示例：

- SuperTrend 从空翻多，同时 30min/1h 动量转正。
- SuperTrend 从多翻空，同时 30min/1h 动量转负。

适合：高波动标的和波段趋势。

风险：参数太敏感会频繁反转，参数太慢会利润回吐大。

## 组合决策模型

每个模型只产生候选信号，不直接下单。候选信号进入统一评分：

```text
TrendDecisionScore = DirectionScore
                   + EntryScore
                   + QualityScore
                   - RiskPenalty
```

### DirectionScore

- 15min / 30min EMA 方向。
- 1h EMA fast/slow 与斜率。
- 4h 收益率趋势和波动 regime。
- BTC 对 ETH/SOL 的市场方向锚定。

### EntryScore

- Donchian 突破触发。
- EMA 回调恢复触发。
- 动量恢复触发。
- 波动扩张触发。
- SuperTrend 翻转触发。

### QualityScore

- ADX 是否达标。
- ATR percentile 是否足够。
- K 线实体占比是否支持方向。
- 最近高低点结构是否顺趋势。
- 成交量或盘口深度是否支持成交。

### RiskPenalty

- 点差过大。
- 资金费对方向不利。
- 距离止损过近或过远。
- 同方向 BTC/ETH/SOL 相关敞口过高。
- 当日亏损或连续亏损达到降仓条件。
- 当前交易预期空间不足以覆盖手续费、滑点和资金费。

开仓规则：

```text
1. 市场状态允许交易
2. DirectionScore 达到最低要求
3. 至少一个 Entry Sleeve 触发
4. TrendDecisionScore 达到开仓阈值
5. RiskAllocator 给出非零风险预算
6. 交易所无外部持仓冲突、无未完成订单、保证金充足
```

## 仓位与组合风险

第一版建议使用风险单位，而不是固定名义金额。

```text
单笔风险 = 账户权益 × risk_per_trade
张数 = 单笔风险 / 止损距离
止损距离 = ATR × stop_multiplier
```

建议初始参数：

| 场景 | 单笔风险 | 说明 |
|---|---:|---|
| shadow / 观察 | 0 | 只记录信号 |
| 小额实盘 | 0.15%-0.30% equity | 验证链路和模型贡献 |
| 稳定后 | 0.30%-0.60% equity | 根据回测和实盘统计逐步提高 |
| 高波动或连亏 | 自动降到 25%-50% | 防止连续假信号扩大回撤 |

组合风控：

- 单标的最多 1 个净趋势仓位。
- BTC/ETH/SOL 同方向相关风险合计设上限。
- XAUT 可作为低相关补充，但不能因为波动低而忽略手续费占比。
- 同一模型连续亏损后，该模型单独降权。
- 同一周期连续亏损后，该周期单独降权。
- 全账户日亏损达到阈值后停止开新仓，只允许减仓/平仓。

## 退出系统

趋势策略的收益来自“亏小赚大”，退出比入场更关键。所有模型共享退出框架。

| 退出类型 | 用途 | 触发示例 |
|---|---|---|
| 初始止损 | 控制单笔最大亏损 | 入场价反向移动 `ATR × k` |
| 移动止损 | 锁住趋势利润 | 价格创新高/新低后 trailing stop 更新 |
| 趋势失效 | 防止趋势结束后硬扛 | 1h 方向反转、EMA 结构破坏 |
| 反向信号 | 方向明确反转时退出 | 多头出现高分空头决策 |
| 时间止损 | 小趋势不动就退出 | N 根 K 线后未达到最低浮盈 |
| 资金费退出 | 合约持仓成本恶化 | 资金费对当前方向持续不利 |
| 熔断退出 | 极端异常保护 | 行情跳变、API 退化、风控阈值触发 |

长期必须补交易所侧条件止损/止盈单。服务轮询止损只能作为第一版，不能作为长期唯一保护。

## 数据与账本设计

已有：

- `htx_trend_signal`：记录当前单模型信号。
- `htx_trend_order`：记录趋势订单生命周期。
- `htx_trend_position`：记录趋势仓位生命周期。

长期需要扩展：

| 表 / 字段 | 用途 |
|---|---|
| `htx_trend_factor_snapshot` | 每轮每标的每周期的因子快照：EMA、ROC、ADX、ATR、通道、资金费、点差 |
| `htx_trend_candidate_signal` | 每个 sleeve 产生的候选信号，记录模型名、周期、方向、分数、原因 |
| `htx_trend_decision` | 组合决策结果，记录 DirectionScore / EntryScore / QualityScore / RiskPenalty |
| `htx_trend_position.model_source` | 记录最终由哪些模型触发开仓 |
| `htx_trend_position.risk_budget` | 记录开仓时风险预算和止损距离 |
| `htx_trend_order.execution_quality` | 记录滑点、成交延迟、预期价差 |
| `htx_trend_model_daily_pnl` | 按模型、周期、标的统计收益和回撤 |

必须能回答这些问题：

1. 哪个标的赚钱，哪个亏钱？
2. 哪个周期赚钱，哪个亏钱？
3. 哪个模型赚钱，哪个亏钱？
4. 盈利来自大趋势还是小趋势？
5. 亏损来自假突破、回调失败、手续费、滑点还是资金费？

## 回测与上线门槛

在增加真实下单前，必须先做离线回测和 shadow 对账。

### 回测要求

- 至少覆盖 BTC、ETH、XAUT。
- 至少覆盖 15min、30min、1h。
- 手续费、滑点、资金费必须进入成本模型。
- K 线使用已完成 K 线，避免未来函数。
- 参数必须做 walk-forward，不能只调到历史最优。
- 输出按模型、周期、标的拆分的 PnL。

### 验收指标

这些不是收益承诺，而是上线门槛：

| 指标 | 最低门槛 | 目的 |
|---|---:|---|
| Profit Factor | > 1.15 | 证明手续费后仍有边际 |
| 最大回撤 | 可被账户风险预算承受 | 防止策略没爆但账户扛不住 |
| 单笔平均收益 / 成本 | > 3x | 短周期尤其重要 |
| 连亏分布 | 有明确降仓规则覆盖 | 防止假趋势连打 |
| 模型贡献 | 至少两个 sleeve 有正贡献 | 避免伪组合 |
| shadow/live 偏差 | 可解释 | 防止回测与实盘断裂 |

## 长期路线图

### M0：稳定当前实盘链路

状态：已基本完成。

目标：保持当前真实趋势服务运行，但不急着扩大仓位。

验收：

- 服务稳定运行。
- 无旧策略外部仓位阻塞。
- `htx_trend_signal` 稳定写入。
- `htx_trend_order` / `htx_trend_position` 在真实触发后能完整记录。

### M1：多标的数据底座

目标：把 BTC、ETH、XAUT 的 15min/30min/1h/4h K 线、资金费、盘口点差统一落地。

产出：

- 标的池配置。
- K 线缓存/补齐机制。
- 因子快照表。
- 数据质量检查：缺 K、重复 K、未完成 K、异常跳价。

### M2：多模型 shadow 引擎

目标：所有模型只产出候选信号，不下单。

产出：

- Breakout sleeve。
- Pullback sleeve。
- Momentum recovery sleeve。
- Volatility expansion sleeve。
- SuperTrend sleeve。
- 每轮记录候选信号和组合分数。

验收：

- 每个模型都有清晰 reason。
- 能看到每个模型在 BTC/ETH/XAUT 上的触发频率。
- 能解释为什么不开仓。

### M3：组合决策与风险分配

目标：从多个候选信号中生成唯一交易决策。

产出：

- TrendDecisionScore。
- RiskPenalty。
- RiskAllocator。
- 相关性风险控制。
- 连亏降权。

验收：

- 同一标的不会多模型重复开仓。
- BTC/ETH 同向不会无限叠加。
- 单笔风险、日风险、账户风险都有上限。

### M4：小额实盘组合

目标：BTC/ETH/XAUT 小额度真实运行。

建议：

- 初始只开 0.15%-0.30% equity 风险。
- 每个标的每日最大新开仓次数有限制。
- 只允许最稳的两个 sleeve 先 live，比如 Pullback + Breakout。
- 其他 sleeve 继续 shadow。

验收：

- 每笔订单有模型来源、分数、止损、退出原因。
- 实盘滑点与回测假设差异可控。
- 策略可以自动降低无效模型权重。

### M5：模型治理与扩展

目标：组合策略进入长期迭代。

产出：

- 模型排行榜：按标的/周期/sleeve 看收益、回撤、胜率、盈亏比。
- 参数治理：参数只允许通过回测 + shadow + 小额 live 三关后上线。
- 新标的准入：流动性、点差、资金费、历史数据长度、交易所稳定性。
- 自动报告：每日生成模型贡献和风险暴露。

## 第一版推荐组合

不要一次性把所有模型都实盘。第一版建议：

```text
Live:
  BTC 30min/1h Breakout + Pullback
  ETH 30min/1h Pullback + Momentum Recovery
  XAUT 30min/1h Pullback + Volatility Expansion

Shadow:
  BTC/ETH 15min Momentum Recovery
  SuperTrend sleeve
  SOL/BNB 等 Tier 2 标的
```

这样做的好处是：

- BTC/ETH 先贡献主要趋势机会。
- XAUT 不再只等突破，而是用更适合低波动的回调/扩张模型。
- 15min 小趋势先 shadow，等真实成本和触发质量稳定后再 live。
- 每一步都能归因，不会一上来变成黑箱组合。

## 当前实现与长期目标的差距

| 能力 | 当前状态 | 长期目标 |
|---|---|---|
| 标的 | XAUT-USDT | BTC/ETH/XAUT + 可扩展标的池 |
| 周期 | 15min 入场 + 60min 方向 | 15min/30min/1h/4h 分工 |
| 模型 | Donchian 突破 | Breakout + Pullback + Momentum + Vol Expansion + SuperTrend |
| 风控 | 单笔 ATR、资金费、点差、外部仓位 | 组合风险、相关性、模型降权、日亏损熔断 |
| 账本 | 信号/订单/仓位 | 因子/候选/决策/模型贡献/PnL |
| 退出 | 轮询止损/反向/资金费 | 交易所条件单 + 服务风控双层保护 |
| 评估 | 线上观察 | 回测 + shadow + live 归因 |

## 推荐下一步

下一步不直接改 live 策略，而是先做 M1/M2：多标的数据底座和 shadow 信号引擎。只有当 shadow 结果能解释“哪些标的、哪些周期、哪些模型值得实盘”，再把最稳的两个 sleeve 放到小额 live。
