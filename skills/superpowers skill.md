# skills - superpowers skill
### 一、Superpowers Skill 简介
Superpowers 是一个开源的、跨平台的技能框架与软件开发方法论，专为AI编程助手（如 Claude Code, Cursor, Codex 等）设计。它的核心使命并非简单地增强AI的编码能力，而是为AI注入严谨的“工程纪律”，将其从一个可能“自由发挥”的代码生成器，转变为一个遵循标准化流程、产出高质量代码的“工程化协作伙伴”。
它通过一套强制性的、结构化的技能（Skills）系统，将软件工程的最佳实践（如测试驱动开发、代码审查、任务拆解、工作区隔离）内嵌到AI的日常开发流程中，从根本上解决了AI编程中常见的“跳步”、“缺乏规划”和“测试覆盖率低”等问题。
### 二、设计理念
Superpowers 的核心理念是**强制执行最佳开发实践**，通过一系列预定义的"技能"（Skills）模块，将复杂的软件开发过程分解为可管理、可验证的步骤。这确保了代码质量、可维护性和开发效率。

## 二、核心功能详解-七步开发工作流
#### 2.1、头脑风暴 (Brainstorming)
* **功能**：在编码前主动澄清需求
* **流程**：AI通过提问明确模糊需求，讨论多种设计方案
* **优势**：确保"想清楚再动手"，避免后期返工

#### 2.2、 隔离工作空间 (Git Worktrees)
* **功能**：创建独立的开发环境
* **流程**：在隔离的 Git 工作树中进行开发
* **优势**：保护主分支代码，实现安全的实验性开发

#### 2.3、任务分解 (Writing Plans)
* **功能**：将大任务拆解为小步骤
* **流程**：把设计方案分解为2-5分钟可完成的原子任务
* **优势**：确保每个任务清晰可执行，降低出错概率

#### 2.4、子代理驱动开发 (Subagent-driven Development)
* **功能**：模块化任务执行
* **流程**：为每个任务创建独立的子代理，执行后进行两阶段审查
* **优势**：保持上下文干净，确保代码质量

#### 2.5、测试驱动开发 (TDD)
* **功能**：强制执行测试优先原则
* **流程**：遵循"红-绿-重构"循环，先写失败测试再实现功能
* **优势**：确保代码可测试性，提高代码质量

#### 2.6、代码审查 (Code Review)
* **功能**：持续质量保证
* **流程**：每个任务完成后自动触发结构化审查
* **优势**：及时发现问题，防止错误累积

#### 2.7、完成开发分支
* **功能**：优雅收尾开发过程
* **流程**：验证所有测试，提供合并或创建PR的选项
* **优势**：确保开发过程干净利落

## 三、 安装与配置
#### 3.1 、系统要求
Claude Code 版本 2.0.50 或更高

Node.js 环境（用于插件管理）

Git 已安装并配置好

稳定的网络连接

#### 3.2 、安装步骤
##### 第一步：添加 Superpowers 市场源
```bash
/plugin marketplace add obra/superpowers-marketplace
```
**说明**：这一步只需执行一次，相当于添加软件源。

##### 第二步：安装 Superpowers 插件
```bash
/plugin install superpowers@superpowers-marketplace
```
##### 第三步：验证安装
```bash
/find-skills
```
**注意**：如果提示命令不存在，请先安装 

```Plain Text
find-skills
```
安装命令

```Plain Text
npx skills add vercel-labs/skills@find-skills -g -y
```
### 3.3、 常见安装问题
|问题|解决方案|
| ----- | ----- |
|安装后看不到新命令|必须完全退出并重启 Claude Code|
|市场源添加失败|检查网络连接，特别是 GitHub 访问|
|权限错误|确保 Node.js 环境配置正确|

### 四、使用方法与工作流
#### 4.1、基础使用
##### 4.1.1、自动触发模式
当你提出开发需求时，如：

> "帮我实现一个用户登录功能"

Claude 会自动调用 

```Plain Text
brainstorming
```
和

```Plain Text
writing-plans
```
 等技能来引导开发

#### 4.1.2、手动触发模式
你可以直接指定使用某个技能：

```Plain Text
请使用 brainstorming skill 帮我设计这个功能
让我们用 write-plan skill 来规划一下
```
#### 4.2、典型工作流示例
##### 场景：开发新功能
**步骤1：需求澄清**

```bash
我想添加一个数据导出功能
```
*AI 自动进入头脑风暴模式，提出问题*

**步骤2：方案确认** *你与 AI 讨论并确认技术方案*

**步骤3：任务分解**

```Plain Text
请为这个功能创建开发计划
```
*AI 生成详细的原子任务列表*

**步骤4：开发执行** *AI 自动为每个任务创建子代理，执行并审查*

**步骤5：测试验证** *AI 自动执行 TDD 流程，确保测试通过*

**步骤6：代码审查** *每个任务完成后自动触发审查*

**步骤7：合并准备** *AI 提供合并代码或创建 PR 的选项*

#### 4.3 高级用法
##### 自定义工作流
你可以跳过某些步骤或调整顺序：

```bash
我已经有设计方案了，请直接开始写计划
```
##### 技能组合使用
```Plain Text
请使用 find-skills 搜索相关的辅助工具
然后用 brainstorming 技能评估这些工具
```

### 五、最佳实践
#### 5.1、项目设置建议
##### 5.1.1、初始化项目
```bash
# 创建新项目目录
mkdir my-project
cd my-project

# 初始化 git
git init

# 启动 Claude Code
claude
```
##### 5.1.2、插件配置
在项目根目录创建 .claude 配置文件

```json
{
  "plugins": {
    "superpowers": {
      "enabled": true,
      "tdd": true,
      "codeReview": true
    }
  }
}
```
