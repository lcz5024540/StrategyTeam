# HTX 合约方案 B：费用感知型 Maker 网格

> 状态：已实现并完成离线验证（2026-08-16）
> 范围：`coin-strategy-htx`
> 安全边界：不部署、不调用真实私有接口，合约实盘开关保持默认关闭

## 1. 问题

历史 XAUT-USDT 双向合约周期用四腿 IOC 快速开平。成交报告显示 62 个周期累计成交额
135,344.29109 USDT，手续费 51.4308525136 USDT，价差与滑点损失 26.70420 USDT，
总损失 78.1350525136 USDT。开仓后立即按外部盘口反向平仓，会稳定支付四腿手续费并重复穿越价差，
不具备正期望收益条件。

## 2. 决策

自动合约周期改为利润优先的 Maker 网格：

1. 开多挂在 best bid，开空挂在 best ask，均使用 `post_only`。
2. 两侧仅按实际成交张数挂 `reduce_only + post_only` 平仓单。
3. 多仓最低卖价、空仓最高买回价分别覆盖实际开仓手续费、预计平仓手续费、资金费缓冲、
   安全缓冲和最低净收益，最后按合约 tick 向有利于收益保护的方向取整。
4. 平仓未成交时持久化为 `CLOSE_PENDING`，后续调度只恢复该周期，不允许重复开仓。
5. 仅在平仓 TTL 到期后，撤销旧挂单并尝试受深度和最大滑点限制的 reduce-only IOC 应急退出。
6. 日净亏损达到上限、连续亏损达到上限或数据库查询失败时，拒绝开启新周期。

## 3. 默认参数

| 参数 | 默认值 |
|---|---:|
| 杠杆 | 5x |
| 单边目标名义额 | 20 USDT |
| 调度间隔 | 5 秒 |
| Maker 单腿费率保守值 | 0.04% |
| 最低净收益率 | 0.10% |
| 资金费缓冲 | 0.02% |
| 安全缓冲 | 0.05% |
| 最大入场价差 | 0.10% |
| 盈利平仓 TTL | 1 小时 |
| 应急退出最大滑点 | 0.10% |
| 单日净亏损上限 | 1 USDT |
| 连续亏损上限 | 3 个周期 |

`HTX_CONTRACT_AUTO_FAST_IOC_ENABLED` 默认改为 `false`，
`HTX_CONTRACT_AUTO_PROFIT_GRID_ENABLED` 默认 `true`。`HTX_CONTRACT_ENABLED`、
`HTX_CONTRACT_LIVE_ENABLED` 和 `HTX_CONTRACT_AUTO_LIVE_ENABLED` 仍默认 `false`，
`HTX_CONTRACT_DRY_RUN` 仍默认 `true`。

## 4. 持久化与恢复

不新增表。`htx_contract_cycle.message` 使用 `MAKER_GRID:` 前缀识别新策略周期，
`htx_contract_leg` 继续逐腿保存订单号、成交量、均价、手续费和已实现盈亏。
服务重启后先查询活动周期和交易所订单状态；查询失败时不撤单、不补单。单边开仓成交后若已安全回补，
周期允许正常结束；仍有仓位时保持 `EXPOSURE`，不会通过修改数据库强制放行。

## 5. 非目标与上线条件

- 不承诺 Maker 单一定会成交，也不承诺每个周期盈利。
- 资金费当前采用配置缓冲，不预测下一期实际资金费率。
- 实盘启用前仍需核对交易所仓位、活动订单、账户杠杆和数据库活动周期，并单独授权部署和开单。
- 本次不删除旧手工 fast IOC 接口；自动调度明确拒绝在 fast IOC 开启时运行。
