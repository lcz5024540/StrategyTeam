## 结论与证据

1. **6笔截图的开仓所在15分钟内，六组参数、两条假设路径均没有同向价格形态。** 不能承诺原方案能抓住这些入场。E2、E4的持仓期间稍后出现形态，其余4笔的持仓期间也未出现；晚出现不等于复现原仓。
2. **全区间并非没有候选。** 每组96个结构身份：55反弹回落、41突破回踩；区域k=0.05、0.10分别产生16、14个假设价格形态，均为SHORT反弹回落。突破回踩为0；结构在阶段完成前被替换或回踩失败均有终态记录。
3. **主要线索是结构选择，而非单纯成本门槛。** 96个计划只有31个触及其区域。最宽松的净R≥1仍保留全部14/16个形态，但截图原入场依然为0。降低净R不能把未触及的结构变成机会。
4. **高计划净R也不证明收益。** 大部分通过R筛选的机会，在样本截止仍没有触及目标或止损；原趋势退出可能更早发生，本诊断没有替它计算订单。两条盘中路径的障碍顺序也有显著差异。

以上是ETH单合约诊断，不能外推为52合约组合结果。现有候选的正式逐笔回放、费用与组合准入仍未完成。

## 数据与方法

- 校验原始归档1167个CAS对象的内容哈希及引用闭包；135条旧入场决策均有直接版本引用。
- 15m共378根：10-27 21:00至10-31 19:15 CST开盘；60m共214根：10-22 21:00至10-31 18:00 CST开盘。两周期各自连续，本份样本同时间无修订。
- 首批归档是10-29 13:03 CST。历史K线仅作预热；结构输入按`max(K线结束时间, CAS recorded_at)`逐个释放，最早完整计划时刻13:03:12 CST。不能声称10月27日起已运行该规则。
- 每次用已可见的最多160根15m/60m输入，复用当前`generate`与Python趋势计算。两版历史配置完全相同；随归档时间选择已知配置及ETH同期`tick=0.01, size=0.01`。
- 归档中的原始candle按序写入：尚未组成两个新鲜完整窗口时等待，不能把中间写盘状态误当作结构失效。594条输入观察点中321条尚无元数据/配置、54条等待新鲜窗口、215条生成计划、4条方向或结构拒绝；这些不是594次真实策略决策。
- 每根K线分别假设O-H-L-C、O-L-H-C，节点位于第0/300/600/899秒；三段线性价格用于拆解阶段，跨bar跳价不补造中间触及。**两条路径不是数学最坏/最好边界**；真实行情可能多次往返。
- 几何识别放松“两笔不同成交ID＋同步BBO”为一次有利价格段，只回答价格形态；不生成伪造的MarketEvent或成交。按规则保留同结构终态、防普通修订重生。生成新结构仍可产生独立几何样本。
- 参考价按真实tick对齐；假设IOC最差价格也按方向取tick。复用现有结构成本公式、1.25ATR失效距离。手续费每边0.0004、滑点每边0.10ATR为假设，并列0.05/0.20ATR敏感性。实际taker费率和资金费缺失，资金费保持UNKNOWN。
- 初始止损与目标接触是独立价格障碍诊断，未模拟真实平仓、趋势保护退出、持仓数量、同合约互斥、账户预算、保护后重入门。机会不能相加成账户利润；经过R筛选也不代表订单通过完整风控。
- 10月30—31日已用于提出假设，不能再充当独立留出验证；本次未选参、不以截取的盈利截图调参。
