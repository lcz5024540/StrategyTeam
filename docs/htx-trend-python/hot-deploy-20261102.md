## 修复与行为

| 问题 | 当前处理 |
|---|---|
| 升级后旧仓套用新退出参数 | 订单提交前存不可变的退出/指标参数、实现指纹及归属；管理时使用旧仓快照 |
| 旧仓没有完整参数快照 | 读取旧进程/旧包实际配置，按精确持仓身份接管；不从新env猜参数 |
| 策略改名后漏管、释放错预算 | 显式保留旧策略owner及原instance_key，贯穿订单查询、成交记账和平仓；遗漏旧owner拒绝接管 |
| PAPER缩池/改新风险参数后拒启或漏管 | 保留原账本身份和初始权益；配置内合约顺序不变，池外旧仓追加管理，原杠杆占用不漂移 |
| 重启后候选重复评估或沿用旧盘口 | 原bar/队列/终态持久化；执行前先持久消费候选，恢复候选刷新盘口、资金费、合约规格再过原门禁 |
| SIGTERM没有完整交接 | 只请求排空；当前步骤收口并落盘，最后释放锁；不调用部署清仓 |
| 未知订单/其他周期恢复失败仍能新开仓 | 所有profile先对账与管理；有未确认状态即禁止新风险，已知价格止损仍可用 |
| 回滚只看版本名 | 目标包实际校验持仓快照与解码运行检查点；未知实现、不兼容包拒绝 |
