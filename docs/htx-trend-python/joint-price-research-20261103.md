# 入场、失效与目标配套研究：修正价格计划，未增加合格机会

作者Codex；2026-11-03；状态final（研究完成）。业务基线f2e0781e，事前协议86b0d27b；仅Python。准入仍为**RESEARCH_ONLY_NOT_ELIGIBLE**。

## 结论

配套计算修正了部分局部入场继承错误目标的问题，但**没有新增净R≥1、1.5或2的合格机会**。修正方向不等于发现了更有收益的交易。

1. ETH盘口2248.55做空时，旧目标2251在错误方向；配到当时已知通道支撑2239后，假设成本净R为0.747，仍不够；另一笔2248.90同类触发为0.786。
2. 若纳入当时更近的已确认局部支撑2246.84，净R分别降到−0.120、−0.082。不能为了达到门槛跳过近支撑，直接采用远目标。
3. 新增约16.5分钟尾段产生8条分组研究触发，三种目标口径均没有净R≥1机会。它是同一短行情的后段核验，不是正式独立留出。
4. 后续盘口观察多数在首次超过2秒的覆盖间隔处截尾，不能据此报告胜率、实际收益或目标最终能否到达。

建议保留“入场、失效、目标必须自洽”的研究检查；当前证据不支持切换策略。继续研究的重点应转为更长且覆盖完整的独立样本与真实成本校准，不能持续拿这批样本改参数追求通过。生产方向仍由用户决定。

## 后续盘口与证据边界

价格路径只检查触发之后、交易所时间和接收时间都更晚的可执行BBO（LONG看bid、SHORT看ask）。当前新鲜度2秒，第一次覆盖缺口即截尾，不跨缺口补推先后。发现的“迟到但仍新鲜的触发前盘口被算触发后触达”已修正并加入回归。

J2在诊断段有4条分组记录触及局部目标（两种k会重复记录同一市场事件），但这些并非净R合格交易；其余合法价格路径基本因报价覆盖间隔截尾。净R≥1.5的记录全部先被覆盖间隔截尾，因此没有可用于收益结论的完整持仓路径。触达目标不能叫已盈利，截尾不能填零亏盈。

本轮没有执行深度、真实下单延迟、账户预算竞争、实际IOC、保护退出重入、15m趋势退出和资金费结算。诊断触发的后续观察可能延伸到尾段，不能声称尾段与诊断完全独立。

另外，本研究沿用原generate所生成的机会集：原算法因缺旧目标而根本不生成的反弹计划，仍未被本轮补建。因此这里覆盖的是原引擎全触发及拒绝的目标对照，不是市场上所有可能的结构计划。
