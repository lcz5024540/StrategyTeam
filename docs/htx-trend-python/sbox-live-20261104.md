## 规则与实现

- S独立评估15m通道/箱体/已确认2左2右局部结构；不接M/T，不调整k/R。目标在事件激活时冻结；仅允许外沿突破且无既有盈利方向边界时采用BOX32测量目标。
- `SBoxEngine`保存中性事实与执行计划两个命名空间，使用同一既有计划表。研究参数指纹转换为明确的生产版本；旧几何生成器拒绝SBOX，不能静默退回旧规则。
- 每个结构最多一次意图。事实已完成但执行计划未保存时，重启拒绝机会；未知/已提交订单保留原身份继续对账。未提交触发断线失效，同一批后续成交或BBO跨越目标/止损后，即使价格恢复也不复活。ARMED/BROKEN/RETEST阶段冻结目标被BBO跨越时也永久失去交易资格，保留结构事实；激活前旧报价不用于撤销目标；已经触发后迟到的盘口也按交易所和接收双时间边界检查。激活接收/交易所时间同次保存，避免IO恢复缺字段。
- 共享风险、IOC价格边界、1.25ATR安全距离、实时初始止损、15m退出及保护退出重入门保持原路径。PAPER落账失败回滚订单和执行状态；事实保存失败阻止新风险。
- `build-live --sbox`绑定唯一参数、spec hash、环境示例及规则说明。旧包构建默认行为保持不变；`structural_candidate_selected=true`表示已选规则，`financial_admission=NOT_ELIGIBLE`如实保留。

## 状态矩阵与影响范围

|入口/状态|处理与验证|
|---|---|
|同结构重复消息/普通刷新|事实ID→稳定plan ID；不会增加订单身份|
|TRIGGERED未提交、断线/重启|持久REJECTED；不追补断线机会|
|SUBMITTED/UNKNOWN|保持原client order ID；已有恢复流程继续查询|
|PARTIAL/FILLED/NO_FILL|终态保留，不用新计划补量|
|事实写入失败/计划写入失败|dirty重试持久化；跨存储崩溃缺口拒绝，不补单|
|PAPER提交失败|订单/待成交/执行状态回滚，事实不回滚；恢复同一身份|
|实时触发排队后目标/失效位被跨越|永久INVALIDATED，不因价格恢复重新有效|
|试运行准入|候选、代码包、参数、账户、池、退出指纹必须一致|
