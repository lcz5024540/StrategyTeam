# 入场、失效与目标配套研究协议
作者Codex；2026-11-03；事前登记；业务基线f2e0781e；用户授权执行上一轮建议。研究不改生产策略。

## 固定对照
使用上一轮A/M/T触发器和两种k(.05/.10)，R门槛1/1.5/2不变。J0保留原目标；J1将反弹回落目标配到当时可见20/32箱体/通道边界；J2在J1基础上加入同组已确认、未失效的反向局部线。A无新增局部线。突破回踩仍用原目标，不追加直接突破策略。

## 目标规则
在反弹回落WAITING→ARMED（实际首次进入区域）时保存目标快照；尚未激活允许更新，激活后不换线。断线重置需重新激活，重新冻结并保留上一快照。只用当时已接收完整闭合15m窗口和已确认局部线；禁止用触发以后才确认的结构。
LONG在L+b之上的有效HIGH阻力中取最近一条；SHORT在L-b之下的有效LOW支撑中取最近一条。相同价格合并来源。局部线仅保留最近32个15m范围，确认后闭合价突破其固定失效带时排除，与上一轮有效性判据一致。目标按tick保守舍入（LONG向下，SHORT向上），舍入后不在区域外即拒绝。反弹没有有效目标时明确NO_TARGET，不凭等幅或固定R补造目标；不跳过近目标选远目标提高R。J2目标可以更近，不保证提高机会数。
触发时盘口跨过已冻结目标则拒绝，不重选远目标。触发来自原两笔成交＋BBO，所有原触发都保留诊断；无目标不下单，也不能以终止状态变更扩大机会。

## 风险与成本
原始结构失效位、区域宽度、reference和1.25ATR安全距离全部保持；断言LONG stop=min(raw,reference−1.25ATR)，SHORT stop=max(raw,reference＋1.25ATR)。不收紧止损提高R。仅替换目标后调用既有cost_geometry；手续费每边.0004、滑点每边.10ATR为假设，.05/.20为敏感性；资金费结算未知，净R不是真实净利润。不增加新参数组合、不选生产参数。

## 后续价格观察（非交易收益回测）
对每条目标合法的触发，记录随后新鲜可执行BBO首次触及冻结目标或冻结初始止损：LONG看bid、SHORT看ask；只从触发之后事件起算，不用开仓前或整bar极值。该合约盘口超过2秒无覆盖、epoch变化、GAP或数据截止即截尾，不跨缺口判先后。不设获利阈值调参，不模拟趋势退出、手续费结算或实际成交。因此TARGET_TOUCH不叫盈利交易，STOP_TOUCH不代表现网退出，未触及不得填零收益。
