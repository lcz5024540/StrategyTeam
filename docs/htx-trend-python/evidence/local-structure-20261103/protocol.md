## B确认与失效

固定研究定义2左＋2右：五根连续闭合15m中，中心high严格大于其余四根为局部高点，low严格小于其余四根为局部低点。相等极值不做任意择点。
最早可用为五根全部闭合且归档的最大时刻；锚点是中心bar，确认bar是右侧第二根，不回填信号。仅比较锚点处于当前32根窗口的结构，使用与原箱体相同历史范围，不新增扫描参数组合。
高点在确认之后任何已知闭合价高于line+b时失效，低点对称。b随本次研究参数按确认时可用ATR14固定，后续不扩大；确认前不能以该线触发。修订只在归档后生效，不重生同身份计划。

## C确认与失效

失败突破必须针对该bar开始前已确认、当时有效的B局部线；跨过去再收回发生在同一闭合bar。做空结构要求bar.high>旧line+b且bar.close<旧line-b；做多对称。参考b采用该bar开始前可见ATR14，与本次k/tick计算，不使用失败bar自身扩大阈值。
新研究线取失败bar极值high/low，确认于该bar已闭合且归档后；不能把这根bar本身算作对新线的反弹触发。新线在随后闭合价突破其失效边界时失效；b固定于确认时，锚点同样限制在32根内。
同一失败bar同方向涉及多条旧线时合并为一条极值线，保留全部旧线引用，不重复制造候选。
