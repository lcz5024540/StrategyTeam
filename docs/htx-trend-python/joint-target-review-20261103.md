## 审查发现与修复

### Required/P2：同包成交共享毫秒被误拒绝（已修复）

原`joint_price_diagnostic.py:262`要求activation_ms严格小于trigger_ms，但HTX同一个WS包的多笔不同成交ID可共享received_ms。依次靠近、入区、两笔确认本来是合法因果序列，研究器却抛AssertionError。

现`TargetEngine.accept`为每次输入记录单调事件序号，目标快照保存激活序号；`JointResearch.observe`同时核对同epoch、激活毫秒不晚于触发、激活事件严格早于触发事件。相同毫秒不再误拒绝，单个事件仍不能同时充当激活和触发。新增测试从真实decode入口构造一包4笔成交，通过完整研究触发记录链路。

### Required/P2：非盘口消息的连接换代未立即截尾（已修复）

原`QuotePaths.observe:168`只在GAP/BBO处理epoch，另一合约的新连接TRADE先到时，旧连接的迟到BBO仍可能被计为触达目标。

现`QuotePaths.observe:179`在按消息类型分支之前处理连接代次；任何带epoch的新输入使全部旧路径截尾。保存已退休epoch，拒绝旧消息及旧book恢复观察路径；显式GAP也退休旧连接。测试覆盖TRADE/BBO/DEPTH、跨合约换代、旧消息迟到及旧盘口追加路径。
