## 改动

新增trial、trial_admission、trial_facts、trial_ops四模块和显式trial状态表。worker先恢复/管理持仓，再刷新trial事实；预检用trial剩余额度收紧原风险配置，broker发送前持久预留。确认零成交才能释放；完整平仓才计数。MySQL版本CAS保护重启与过期写入者。原退出及重入公式、4H和旧策略默认路径不变。

独立许可绑定账号、实例、提交、包、参数、执行配置、退出policy和52池；MANAGEMENT不允许入场，不计时。TRIAL还须正式运行候选和确认文件。修改环境中的执行配置不能继续使用原许可。旧3仓上限仅在独立trial入口由已授权10仓上限替代；总风险、保证金继续取原严格值。

真实累计成交回执与账本数量交叉核对；开仓费按已平/剩余分摊，资金流水按逐仓合约及真实持仓时段归属。读取发生在后台，不阻止已有价格止损；覆盖缺失时新增风险被拒绝。空仓管理模式不订阅52全池、不反复存空事实对象。

## 验证与限制

- 真实历史4笔订单包含TRX部分退出；均是market，不能冒充IOC实测。
- TRX真实资金费支出0.00315287U，分页至空；其余三笔相应持仓窗口返回空页。真实回执＋错误/缺失费用注入分别验证，不把故障注入称为真实事故。
- Python全量、隔离MySQL及打包证据随最终检查点归档。测试不是收益验证。
- 新试运行尚未激活；真实IOC自然信号验证、唯一候选确认及正式收益对照仍待后续。
- 账户费用/结算与2秒行情时效不满足即阻新风险，可能减少机会，不通过放宽控制解决。

正确性：区分新旧策略损益、浮盈不抵扣已实现亏、每意图幂等、并发笔数不超10、停止不漏管。测试：真实订单/资金流水、额度与恢复、隔离数据库、默认兼容。设计：单writer，显式迁移，独立trial授权，现有退出复用。风格：Python，新增模块和明确边界；不修改研究选参。性能/安全：事实读取后台化，未知覆盖关闭入场；许可无凭据，封存是完整性校验不是签名。

关联探索依据：factory.live→RealtimeWorker._preflight→LiveBroker.submit→Trial.reserve；tick→LiveManagement.tick→BackgroundTrialMonitor→Trial.observe。代码图工具本轮不可用，使用Explore只读源码定位与函数调用证据；没有伪称生成工具图。相关研究缺陷DL-077/DL-078模块未修改。开发自测中发现的离线回放无文件路径、空仓WS与取消状态拼写问题已修正并回归，没有部署这些中间版本。
