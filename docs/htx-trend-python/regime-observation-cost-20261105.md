## 运行边界与下一步

- LIVE非空资金流水是账户/合约级，无法仅凭本地无重叠仓位排除手工交易，保留原流水但不自动认领。完整空覆盖才可记0；本地重算只有明确归属证据才能包含资金费。
- 缺历史平仓参考价时退出滑点未知；LIVE每60秒最多读取10个持仓并轮转旧仓，告警不是逐tick硬实时。
- 原有源码封印机制仍生效；本轮未修改快照有效期或自动刷新。旧源码生成的后验不能手改hash后装入新包；`qa-posterior.json`仅是合成验收夹具，禁止用于真实交易授权。
- 本轮没有选定服务器、账户或生产实例，也没有关闭已有准入来制造订单。开启开关不等于必有订单：既有成熟后验门仍可能拒绝证据不足的机会。

第一步：账户持有人明确要运行的PAPER/LIVE实例、账户及现有部署目录。第二步：按既有规则提供与当前源码匹配的真实冻结后验/账户配置，再加载包内已开启env；LIVE仍由持有人完成原授权流程。第三步：核验运行开关、实际新计划/订单及`REGIME_COST_OBSERVATION`日志，使用真实样本评估结果，不以本轮合成测试推断收益。
