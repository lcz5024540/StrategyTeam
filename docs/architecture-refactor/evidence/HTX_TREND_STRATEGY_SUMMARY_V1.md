## 市场假设

1. 趋势不是单一指标分数：趋势启动、回踩延续和加速阶段分别由 Donchian、Fibonacci、EMA/VWAP 动量模型描述。
2. 同一批 K 线可同时产生多个模型证据，但每个模型必须独立记账；共现不能直接加倍仓位。
3. 只有有方向、波动足以覆盖成本且结构未失效的行情，才可能有趋势收益；`RANGE`、低波动、异常点差和薄盘口不是趋势开仓的默认场景。
4. 研究结果必须在下一根已完成 K 线开盘成交、双边成本和不利滑点假设下仍为正，才有资格进入纸面验证。

## 买入条件

这里的“买入”包含开多与开空，方向相反、规则对称。

1. 只使用已收盘 K 线；数据不足、方向 `FLAT` 或 15m 以外的候选合同不进入开仓链。
2. 组合信号满足默认趋势状态，并通过分数、EMA、ROC、ATR、ADX、成交量的基础判定。
3. 至少命中一个独立模型：
   - **Donchian 突破**：突破 20 根通道，并具备箱体或趋势上下文；
   - **Fibonacci 回踩延续**：前序突破后，价格回到 `0.382–0.618` 区间并重新确认；
   - **EMA/VWAP 动量延续**：EMA 多/空头排列、ROC 同向且 ADX `>=20`。
4. 通过策略政策、实际可成交价格、手续费、保证金、杠杆、盘口点差与深度、开放订单、外部仓位、最大并发及追价 Gate 后，才可生成真实订单意图。

## 卖出条件

完整、统一的退出合同尚未完成成本回测；当前代码的退出候选按以下优先级设计：

1. 模型失效价或初始风险边界被穿越：全平。
2. 持仓趋势反向或衰竭、资金费成本恶化：由退出引擎产生减仓或全平建议。
3. 已达到利润武装条件后，ATR trailing、MFE 回吐、结构保护价与多周期证据共同决定保护、减仓或 runner 退出。
4. 固定比例分批止盈开关默认关闭；不能把“某个候选曾建议减仓”记成已验证的真实止盈规则。

## 止损规则

- **初始止损**：模型失效价与 `2.5 ATR` 风险距离共同参与，不以固定价格比例取代结构失效。
- **移动止损**：`2.0 ATR`，激活门槛为 `1R`；Fibonacci 仓位由 v4 利润保护状态机补充保护价、MFE 和回吐证据。
- **硬风险优先**：模型失效、初始止损优先于“等待趋势确认”。
- **验证边界**：上述退出规则尚未与当前三模型、完整多周期、真实价格计划合并为同一份样本外收益曲线，不能声称其已降低回撤或提高夏普。

## 测试集结果

独立样本外的三模型结果如上表：Donchian、EMA/VWAP 与 Fibonacci 全部为 `REJECT`。Fibonacci 虽然扣费后净收益为正，但 PF `1.1252` 低于准入门槛 `1.30`；其余两个模型净收益、PF 与期望均不通过。

## 最大风险

1. 当前独立样本外策略组合尚无正期望证明；Fibonacci 的正净收益不足以授权实盘。
2. 空头样本明显拖累：放开公共趋势状态后新增空头在 1h、4h 都是负期望。
3. 固定标签持有期没有接入完整退出 v4，无法证明实际利润保护、runner 或止损对组合收益的影响。
4. 回测尚未把实际盘口、限价未成交、部分成交、资金费、跨币相关性和最大并发统一模拟，容量和真实成本仍可能使结果恶化。

## 失败案例

- **公共趋势状态消融失败**：放开 `RANGE / LOW_VOLATILITY` 后，候选增加 14.0%，但新增组 1h PF `0.665`、4h PF `0.853`，都低于基线；不能以“机会变多”替代质量。
- **Donchian 独立样本外失败**：8,340 笔、净 `-1958.1303U`、PF `0.8241`、回撤 `-1968.0601U`。
- **EMA/VWAP 独立样本外失败**：3,663 笔、净 `-220.4712U`、PF `0.9468`。
- **Fibonacci 未达准入**：虽然净 `+1740.7206U`，但 PF 仅 `1.1252`，回撤 `-370.4102U`，不能上线。

## 策略局限性

- 研究模型、实时执行和退出 v4 尚未形成一条可同源统计的完整回测链。
- 目前没有报告完整组合的训练/验证/样本外结果、夏普、无成本收益、基准成本收益和风险调整后容量。
- 市场分型统计模型（GHMM / MS-AR）仍是证据层，未通过验证前不能影响真实开仓。
- 当前白名单、名义额、最大并发和费率均可能被环境覆盖；本文记录的是代码默认合同，不是服务器实时配置快照。

## 最终结论

**继续研究。** 当前策略不能恢复或扩大真实趋势新开仓：三类独立模型均未通过样本外准入，唯一正净收益的 Fibonacci 仍未达到 PF 门槛。保留公共 `TRENDING_UP / TRENDING_DOWN` 前置条件，不将其降级为实盘开仓放行。

## 下一步计划

1. 以同一冻结数据和同一价格计划补齐三模型的无成本、仅手续费、手续费+滑点三档结果，以及训练、验证、样本外、Walk-forward 四段报告。
2. 对 `primary_model + confirmation_models + score_threshold` 做下一项**单条件**消融，定位为何真实候选长期偏向 Fibonacci，而不是放松趋势状态。
3. 将 1d/4h/1h/30m/15m 多周期过滤、市场状态、组合排序和退出 v4 接入同一事件驱动回测；同 K 线按保守止损优先。
4. 纳入账户实际费率、盘口、限价/IOC 未成交与部分成交、资金费、最大并发和相关性约束，再重新计算净收益、最大回撤和夏普。
5. 只有每个模型及组合的独立样本外满足净收益 `>0`、PF `>=1.30`、期望 `>0`、样本量和回撤预算时，才进入纸面验证；不满足则淘汰或重写模型合同。
