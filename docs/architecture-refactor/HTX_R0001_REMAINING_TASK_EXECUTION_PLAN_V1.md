## 4. 已在执行但不能提前宣称完成

### Shadow 观察

独立 shadow 服务已经启动，当前只做候选、诊断和心跳记录。它可以回答：15m 与 4h 各自产生多少候选、哪些被 policy 拦截、是否有数据异常；它不能回答正式实盘收益，也不能证明 4h 高周期确认有效。

观察期至少覆盖 2–3 个完整交易日，并按周期、模型、方向和 gate 结果统计：候选数、通过数、模拟成交数、预期净收益、持仓时长、MFE/MAE 和退出原因。观察期间主 LIVE 保持原 R0 包，禁止把 shadow 结果自动写成真实订单。

### 当前已知异常的处理方式

曾出现一次 shadow `gate_result` 超过旧列宽的失败，已通过追加式 SQL 和 `83b0e56e` 修复；修复后服务恢复 `HEALTHY`。这笔失败保留为证据，不删除。后续只需确认不再复发，并在报告中区分“历史失败”和“当前状态”。
