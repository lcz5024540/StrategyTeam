### 2.1 试探性限价单的边界

该任务不是“把市价单一律改限价单”。趋势突破中，被动挂单会降低费用和追价，但也会错失行情；因此候选方案只在**已通过最终 Gate**后生效：

1. 多头以买一或规则化的可成交限价探路，空头以卖一或规则化的可成交限价探路；价格规则必须可配置、可回放。
2. 挂单只在当前入场窗口内有效；信号过期、点差恶化、反向结构或风险状态变化时立即撤销。
3. 部分成交只按真实成交量建仓；剩余部分不得无条件追价补齐。
4. 是否允许一次重新报价、是否允许转主动成交，必须作为独立开关和回测实验，不能隐式升级风险。

## 6. 执行顺序

1. `OBS-01`、`OBS-02`、`OBS-03`：先让每个不开仓和每个订单都可解释。
2. `BT-01`、`BT-02`：再以历史数据判断哪些 Gate 保留、放宽或分层。
3. `ENTRY-01`：在确认有效候选和成本优势后，设计并回测试探性限价单。
4. `EXIT-01` 至 `EXIT-05`：用同一回测框架评估退出，不单独凭单笔盈亏改规则。
5. `DASH-01`、`DASH-02`：把已验证的真实数据沉淀为驾驶舱。
6. `ARB-*` 与 `CAPITAL-01`：在趋势和账本口径稳定后恢复双引擎资金体系。
