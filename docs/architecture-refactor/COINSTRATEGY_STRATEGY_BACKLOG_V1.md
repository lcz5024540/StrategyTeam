# CoinStrategy 策略未完成任务清单 v1

> **结论先行**：当前趋势策略不应继续直接调低阈值或改变实盘下单方式。执行顺序调整为：先定义高质量候选的 `TrendState` 与模型专属证据，再生成可回放的价格计划，接着向外部**模拟执行器**发布信号并回传成交，最后才评估限价实盘与退出灰度。任何步骤都不得直接扩大真实仓位或绕过最终 Gate。

### 2.3 试探性限价单的边界

该任务不是“把市价单一律改限价单”。趋势突破中，被动挂单会降低费用和追价，但也会错失行情；因此真实候选方案只在**已通过最终 Gate、已生成价格计划、已完成模拟执行回放**后生效：

1. 多头以理想成交价至最差成交价区间内的规则化限价探路，空头反向处理；价格规则必须可回放，不以即时 ask/bid 代替价格计划。
2. 挂单只在当前入场窗口内有效；信号过期、点差恶化、反向结构或风险状态变化时立即撤销。
3. 部分成交只按真实成交量建仓；剩余部分不得无条件追价补齐。
4. 是否允许一次重新报价、是否允许转主动成交，必须作为独立开关和回测实验，不能隐式升级风险。
