# HTX 趋势指标证据与消融验证 v1

## 1. 目标与边界

本计划解决“增加 MACD、RSI、成交量或 AHR999 是否真的提高开仓质量”的问题。第一阶段只记录和验证，不将新增指标写入真实开仓 Gate、仓位放大、HTX 下单或退出 v4。

指标不能叠成一个总分。每个模型只读取其被回测证明有增益的独立信息，避免把 EMA、ROC、MACD 等同源动量重复计分。

| 因子 | 计划职责 | 禁止用途 |
|---|---|---|
| 成交量/成交额/影线 | 突破量能、回踩缩量再启动、假突破与量价背离证据 | 单独开仓。 |
| RSI | 回踩质量、极端位置、恢复或失败摆动证据 | 用固定 70/30 机械反向交易。 |
| MACD | 动量加速/衰减，辅助 Donchian 或 EMA/VWAP 的启动确认 | 与 EMA/ROC 重复加分。 |
| AHR999 | BTC 日线/周线宏观风险状态，影响全局风险预算研究 | 山寨币 15 分钟开仓触发，或把 HTX 日线代理冒充 AHR999。 |

## 2. 已完成

### 2.1 运行时证据

`HtxTrendIndicatorObservationCalculator` 已在全部真实开仓决定完成后运行的 P2 多周期快照链路中计算：

- RSI(14)：数值与区间；
- MACD(12,26,9)：线、信号线、柱体及柱体变化；
- 参与度：相对成交量、相对成交额、最近三根相对前序三根的量能比例；
- K 线质量：收盘位置、实体比例、上下影线比例。

快照升级为 `trend-factor-multi-v2`，每个周期带 `trend-indicator-observation-v1`。该链路处于候选扫描、最终 Gate 和订单提交之后，持久化失败也不得阻塞交易。`AHR999` 记录为 `NOT_AVAILABLE`，直至接入有版本、来源、时间戳和历史修订记录的权威外部数据源。

### 2.2 离线消融工具

新增 `htx_trend_indicator_ablation.py`。它只接受 COMPLETE 冻结清单和由研究引擎产生的扣费后标签；按模型、方向、训练/验证/样本外三个时间区间分别统计 RSI、MACD、成交量分桶和成交额分桶的交易数、胜率、净收益、PF 和期望。成交量与成交额始终分开统计，不互相代替。

工具绝不联系 HTX、数据库或账户，也不输出可部署参数。其输出固定为 `OBSERVE_ONLY`。

## 3. 首次冻结数据结果

输入是 2026-07-03 至 2026-10-03 的 52 个币种 COMPLETE 冻结集，81,531 条研究标签，使用研究引擎的同一费用、滑点和固定持有窗口假设。它不是生产 v4 执行回放，不能直接改实盘。

样本外结果按方向拆分后显示：

| 模型×方向 | 样本数 | PF | 扣费后净收益 | 结论 |
|---|---:|---:|---:|---|
| Fibonacci 多 | 4,657 | 1.29 | +2,212.62 | 值得继续研究。 |
| Fibonacci 空 | 4,321 | 0.93 | -471.90 | 不具备推广条件。 |
| EMA/VWAP 多 | 1,978 | 1.07 | +160.96 | 接近持平，尚不授权。 |
| EMA/VWAP 空 | 1,685 | 0.80 | -381.43 | 不具备推广条件。 |
| Donchian 多 | 4,843 | 0.89 | -764.18 | 不具备推广条件。 |
| Donchian 空 | 3,497 | 0.71 | -1,193.95 | 不具备推广条件。 |

Fibonacci 多头样本中，RSI `UP`（55–70）有 1,346 笔、PF 1.27；`NEUTRAL`（45–55）有 3,252 笔、PF 1.30。该结果说明 RSI 可能提供分层证据，但尚未证明“加 RSI Gate”优于当前基线：仍需固定阈值后，在独立样本和纸面成交中复验，且要加入执行价格、盘口与实际退出。

## 4. 后续执行顺序

1. 部署只读快照并验证生产首条 `trend-factor-multi-v2` 与 K 线归档可按合约、周期和 barTime 对齐。
2. 将运行时快照按模型、方向、市场分型和周期与成熟前瞻结果关联；增加同一模型的消融报告，不混合多空。
3. 在训练段只选择有限、事先声明的候选规则；验证段固定规则；样本外段只验收，不再调参。
4. 只有当新增因子在同一模型×方向×市场状态的样本外和纸面成交中同时提高扣费后 PF、期望并且不把交易数降到不可用，才申请单一 Gate 的小仓灰度。
5. AHR999 单独评审数据源、计算口径、许可、修订策略和日线更新频率；数据源未批准前一直保持 `NOT_AVAILABLE`。

## 5. 验收标准

- 实盘快照只读且异步；不开启或关闭任何交易开关。
- 一条快照可追溯到完整 K 线窗口和指标参数版本。
- 消融报告按模型、方向、市场状态和样本区间拆分，费用计入净收益。
- 任一因子在样本外 PF、期望或交易容量未改善时，明确保留为观察，不进入真实 Gate。
