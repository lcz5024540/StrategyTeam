## 维护约定

- **新增文档**后，在对应主题 MOC 里补一条链接；新主题则新建一个 `MOC-xxx.md` 并登记到本页表格。
- 文档间链接统一用**相对路径**，保证在 GitHub / IDE / Obsidian 都能跳转。
- 过时文档不直接删除，标注 `status: archived` 或移入归档目录（需先确认引用关系）。
- 标签取自 [标签体系](标签体系.md)，不随意发明。
