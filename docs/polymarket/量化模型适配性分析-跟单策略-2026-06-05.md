# 量化数学模型适配性分析：哪些模型适合当前跟单策略（2026-06-05）

> 问题：当前代码里的量化数学模型，哪些适合「Polymarket 聪明钱跟单」这个策略？
> 方法：先认清策略的数学本质，再逐模型给「适配 / 错配 / 缺失」判定与修正方向。结论基于源码实读（`sizing/KellyCalculator`、`TradeProfitabilityScoringService`、`PolymarketConsensusSignalService`、`MarketPriceImpactEstimator`、`Leader*Drift/Rolling`、`WalletArchetypeClassifier` 等）。

---

## 0. 先认清策略的数学本质

Polymarket 跟单与「连续价格 + 技术指标」的量化交易**本质不同**，决定了模型取舍：

1. **价格即概率、结算到 0/1**：token 价 ∈ (0,1) 就是市场隐含概率，到期结算为 1（赢）或 0（输）。⇒ 这是**伯努利/二项**世界，不是连续收益世界。
2. **payoff 有界且非线性**：买价 p、赢则 +(1−p)/p、输则 −1。⇒ **Kelly、EV 这类「已知赔率的重复下注」模型天然契合**；而均值回归、GARCH、动量这类连续序列模型基本不适用。
3. **alpha = 选对 leader + 及时复制**：edge 来自 leader 的信息优势，被**复制延迟**衰减。⇒ 核心要建模的是 **P(跟随的 outcome 结算为真 | leader 行为, leader 质量, 市场价, 延迟)**，这是一个**带校准的条件概率分类问题**，下游接 EV + 仓位。
4. **小样本 + 选择偏差**：单个 leader 的历史成交少、且我们是「挑过去赢家」。⇒ 必须用**收缩/区间估计 + 多重检验校正**，点估计胜率不可信。

> 一句话目标架构：**Beta 后验估 leader 胜率 → 校准出 P(win) → 净EV 决策 → 相关性感知的分数 Kelly 定仓**，全程带复制延迟与集中度约束。下面对照现状。

## 1. 现有模型逐项适配判定

| 模型（代码） | 数学形式 | 适配跟单？ | 判定与问题 |
|---|---|---|---|
| **分数 Kelly 定仓** `KellyCalculator` | f*=(p·b−(1−p))/b，stake=capital·fraction·f* | ✅ 模型对、**输入错** | Kelly 是预测市场定仓的正解；但 `p` 用的是被压缩的「跟单值得度」`p=0.5+(follow−0.5)·edgeFactor`（生产 edgeFactor≈0.15 把 p 压到 ~[0.46,0.575]），不是真实 P(win) → Kelly 退化成「价格<~0.575 拒、<~0.46 过」。**右模型喂错变量**。 |

## 2. 缺失但**更适合**本策略的模型（建议引入）

按对「跟单正确 + 盈利」的价值排序：

1. **Beta-Bernoulli 后验 / Wilson 下界估 leader 胜率**（★最高）
   - 现状：胜率=wins/total 点估计，小样本极不稳，且选 TOP-N 有幸存者偏差（审计 R13）。
   - 模型：把每个 leader 的胜率当伯努利比例，用 **Beta(α₀+wins, β₀+losses) 后验**，取**后验均值或可信下界**（或 Wilson 95% 下界）作为「可信胜率」，向市场基准率收缩。
   - 价值：直接修正 leader 选择与 P(win) 的输入，杜绝「运气好的小样本」被选入。

2. **校准的 P(win) 概率模型（替换被压坏的 Kelly 输入）**（★最高）
   - 模型：`P(win) = f(leader 揭示价, leader Beta 后验胜率, 共识强度, 市场价, 到期时间, 复制延迟)`，用**逻辑回归/贝叶斯校准**输出真概率；最朴素可行版：以 **leader 成交价 / 当前市场价作为隐含概率先验**，再按 leader 质量做贝叶斯修正。
   - 价值：让 Kelly/EV 吃到「真实结算概率」，是整个数学链路正确性的基石。

3. **复制延迟的 edge 衰减模型**
   - 模型：edge(Δprice, Δt) —— 把「我方入场价 − leader 价」与时间滞后建成显式衰减项，进入 EV；偏离超阈直接拒（已部分由 G14 追高门覆盖，但缺连续衰减）。
   - 价值：跟单的逆向选择主要来自延迟，显式建模比硬阈值更精细。

4. **相关性感知 / 同时下注的 Kelly（多腿 Kelly）**
   - 现状：单笔 Kelly 各自计算，同事件多腿会**过度下注**（单笔 Kelly 假设独立）。
   - 模型：对同事件/相关簇用**联合 Kelly 或风险预算**收缩，配合 negRisk 互斥约束（审计 P0-3/R6）。
   - 价值：控预测市场最大的尾部来源——隐性杠杆 / 必有一输的对冲漏洞。

5. **leader 选择的多重检验校正**
   - 模型：挑 TOP-N 时加**最小样本量 + 最小效应量 + Benjamini-Hochberg / 显著性**，而非单纯按胜率排序。
   - 价值：把「选过去赢家」从过拟合变成统计上站得住。

## 3. **不适合**本策略的模型（避免误用）

- **技术分析 / 动量 / 均值回归**（代码库里 `core/technical`、`BtcFairProbabilityService`、`weather*` 等）：这些服务于连续价格序列或特定结构化市场，**不应**引入聪明钱跟单——跟单信号来自链上行为，不是 K 线形态。
- **GARCH / 波动率聚类**：预测市场价是趋向 0/1 的有界鞅，不存在围绕某水平的方差聚类，波动率时序模型价值有限（C3 的「短窗波动熔断」是风控阈值，不是波动率预测模型，二者别混）。
- **连续收益的均值-方差(Markowitz)组合优化**：payoff 是二元非高斯、强相关（同事件），均值-方差假设失效；应改用 **Kelly/风险预算 + 互斥约束** 的组合方法。

## 4. 推荐的「目标模型栈」（与现状的差距）

```
[特征] leader Beta后验胜率 · 共识强度(去重) · 揭示价/市场价 · 到期 · 复制延迟
   │
   ▼  (1) 校准 P(win)  ← 逻辑回归/贝叶斯校准（修复：不再用压缩的 follow 分）
   ▼  (2) 净 EV = P·(1−price) − (1−P)·price − fee − E[slip]   ← 开启为硬门
   ▼  (3) 分数 Kelly（相关性/同事件收缩 + negRisk 互斥约束）  ← 修复过度下注
   ▼  (4) 复制延迟衰减 + 集中度/资金曲线(E1)/熔断(G0) 约束
```

差距小结：**(1)(2)(3) 的「模型选型本身都对、但要么喂错输入、要么默认关闭、要么缺相关性约束」**。也就是说——**当前策略不缺合适的模型框架，缺的是把 Kelly/EV 的概率输入做对（Beta 后验 + 校准 P(win)）、把净 EV 门打开、并加相关性/互斥的组合约束**。这三件事的优先级高于引入任何全新模型。

---

## 5. 一页结论

- **最适合且已具备（保留强化）**：分数 Kelly、净 EV、共识去重、recency 加权+收缩、VWAP 滑点、leader 漂移/滚动、archetype。
- **最适合但缺失（建议补）**：Beta/Wilson 胜率估计、校准的真 P(win)、复制延迟衰减、相关性感知 Kelly、leader 选择显著性校正。
- **最该先修（不引新模型）**：① Kelly/EV 的 `p_win` 语义（用 Beta 后验 + 价隐含概率，弃压缩 follow 分）；② 打开含手续费+滑点的净 EV 硬门；③ 同事件/相关性下注收缩 + negRisk 互斥。
- **避免误用**：技术分析/动量、GARCH、均值-方差组合优化——与二元预测市场的数学结构不符。

> 注：本文为模型选型分析，未改动代码。其中「修 p_win / 开净 EV 门」即审计 P0-2，「negRisk 互斥」即 P0-3，与既有风险清单一致；若要落地，建议先在 PAPER 用影子账本对照新旧 P(win) 校准曲线，再切换。
