## 冻结策略与接口
1h闭合EMA20/60方向；15m闭合20通道/32箱体/ATR14；15m明确反向拒绝，FLAT可入且真实传退出。相同边界合并来源；结构锚点定身份，时间/普通修订不重建开仓身份。
反弹：从安全侧进入[L-b,L+b]，离开回到顺势侧后连续两个不同成交ID与同步BBO确认。突破：两笔越界后单独回踩阶段，再两笔同向越界+BBO；不直接追突破。
区域b=max(2tick,k*ATR)，k={.05,.10}；最低净R={1,1.5,2}，仅6组。结构失效位=激活/回踩极值外加b，最终LONG=min(结构位,参考入场-1.25ATR)、SHORT=max(结构位,参考入场+1.25ATR)。stop/invalidation采用同一合成边界，提交后冻结。
目标是盈利方向最近既有边界；突破全部范围才使用32箱体等幅目标，来源分列。真实tick/taker费/滑点/资金费与账户预算复用，不猜未知费用。
StructurePlan / RealtimeTrigger / EntryIntent分别保存结构时钟、触发时钟和执行意图；默认2秒新鲜度。拒绝/零成交/失效终态，已提交计划不自动追单。按接收顺序、同批次净R降序/计划ID裁决。

## 幂等与故障矩阵
- 状态：WAITING -> ARMED/BROKEN -> RETEST -> TRIGGERED -> REJECTED或SUBMITTED -> FILLED/PARTIAL/NO_FILL/UNKNOWN；UNKNOWN只查询原client ID。
- 每计划最多一个订单意图；部分成交立即纳入止损，撤余单未确认不得释放预算。
- 重复/乱序/断线重连不累计两笔确认；同价新bar不产生新身份；普通修订不能复活终态。
- 首笔成交前极值/旧bar确认不计入持仓。缺口期间只停止新风险与证据依赖保护，独立初始止损继续。
- 同一仓只允许一个未决平仓；真实账本失败明确故障，不能假成功。
- gzip流采样上限2GiB，不删除旧证据，覆盖不足不作正式回放。
